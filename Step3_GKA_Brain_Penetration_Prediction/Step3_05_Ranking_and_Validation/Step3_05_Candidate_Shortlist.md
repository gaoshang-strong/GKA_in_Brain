## ⚠ 先说这张表**不是**什么

**它不是 Step3_05 的候选名单，是一张待讨论的观察清单。**

两条筛选规则用的都是**文献习惯值**（`概率 > 0.5`、`MW ≤ 400`、`TPSA ≤ 90`），
**从未在本项目的入脑对照集上标定过**。
按 CLAUDE.md 的方法论，阈值必须用对照标定、自检写死在脚本里——这件事属 Step3_05 的正题，还没做。
所以本表的用途只有一个：**把需要讨论的分子摆上桌**。

还有两条限制，任一条都能推翻表里的排序：

* 这些分子处在**外推区**（见 `Step3_05_Fig3_ChemicalSpace.png`）——
  GKA 候选的 MW 与 TPSA 超过了阴性对照，模型在这片区域的可靠性未经评估。
* **入脑只是一个维度**。表里效力最好的是 `GKA_0061`（P2 档），其余多为 P4（0.32–1 µM）。

## 三组行，`rule` 列区分

| `rule` 取值 | 行数 | 含义 |
|---|---:|---|
| `A_both_tools` | 3 | **两个工具都判能入脑**：SwissADME `BBB permeant = Yes` **且** ADMETlab `BBB > 0.5` |
| `B_cns_space` | 9 | **落在 CNS 常见区且模型也说能进**：MW ≤ 400 且 TPSA ≤ 90 且 ADMETlab `BBB > 0.5` 且 SwissADME 判**非** P-gp 底物 |
| `A_both_tools+B_cns_space` | 1 | 两条都命中（`GKA_0492`） |
| `C_gka_control` | 12 | **GKA 身份对照**——已知的临床/参比 GKA，无条件全部写入 |

A/B 合计 **11 个分子 / 10 个骨架**；A 与 B 的并集去重后是 11，不是 3 + 9 = 12，
因为 `GKA_0492` 两条都命中。

### ⚠⚠ C 组是参照物，不是候选，而且回答的是**另一个问题**

那 12 个对照证明的是「**这个分子是不是 GKA**」，**不是「能不能进脑」**。
本项目**没有它们任何一个的实测脑暴露数据**，所以它们
**既不能当入脑阳性对照，也不能当入脑阴性对照**——
"它们是外周药所以应该判为不入脑"是未经验证的推断，不是事实。

放进本表只有一个用途：**看看已知的 GKA 药在这套预测里落在什么位置**，
让 A/B 两组的数值有个熟悉的参照。**不要拿 C 组标定任何阈值。**

顺带一提，C 组里有两对是**同一个药的盐与游离碱**
（`GKA_0057`/`GKA_0783` 是 MK-0941，`GKA_0784`/`GKA_0786` 是 Globalagliatin），
去盐后结构相同、共用同一次工具提交，所以两行的预测值完全一样——**这是正确的，不是重复计算**。

## 逐列说明

### 身份（4 列）

| 列 | 是什么 |
|---|---|
| `mol_id` | 本项目内部编号（`GKA_####`），Step3 全程用它对齐，唯一 |
| `source_id` | **ChEMBL ID**，回 ChEMBL 官网查原始活性数据用这个 |
| `compound_name` | 化合物名。**多数为空**——它们是文献化合物，没进过开发流程，所以没名字 |
| `gka_max_phase` | 临床阶段（1/2/3；空 = 没进过临床） |

### 命中了哪条规则（3 列）

| 列 | 是什么 |
|---|---|
| `rule` | 见上表；多条用 `+` 连接 |
| `gka_is_positive_control` | 是否为 12 个 GKA 身份对照之一（`True`/`False`） |
| `gka_control_name` | 对照的名字（仅 C 组有值） |

### SwissADME（2 列）

这个工具返回 48 列，**只留了这 2 列**——按本项目的口径，其余对入脑判断没有增量信息。

| 列 | 取值 | 怎么读 |
|---|---|---|
| `swissadme_bbb_permeant` | `Yes` / `No` | **不是机器学习模型**，是画在 (TPSA, WLOGP) 平面上的一个椭圆（BOILED-Egg 的"蛋黄"）。落在里面就 Yes。实测本项目 141 个 No 里没有一个落在 Yes 点围成的区域内部——完全可分，这就是几何规则的指纹 |
| `swissadme_pgp_substrate` | `Yes` / `No` | 是否被外排泵 P-糖蛋白泵出去。**这一列才携带独立信息**（81 个 No 落在 Yes 的区域内部，说明用了 TPSA/LogP 以外的东西） |

⚠ **两列必须一起看**。只看 `BBB permeant` 会漏掉"物理上能穿膜、但被泵回去了"这种情况。
表里 `GKA_0718` / `GKA_0639` 就是这样：BBB 判 Yes，但同时被判为 P-gp 底物。

### ADMETlab 3.0（4 列）

这个工具返回 123 列，**只留了这 4 列**。

| 列 | 范围 | 怎么读 |
|---|---|---|
| `admetlab_bbb` | **0–1 的概率** | 机器学习模型给的入脑概率。⚠ **不是 Yes/No，和 SwissADME 那列不能直接对齐**。参照：实测能进脑的对照中位 0.97，实测不能进脑的 0.03 |
| `admetlab_pgp_sub` | 0–1 概率 | 是不是 P-gp 底物。⚠ **这一项两个工具给出几乎相反的图景**——SwissADME 判 GKA 候选 51.8% 是底物，而本列在 GKA 候选上的中位只有 0.001。分歧本身不算错误，但不能简单投票 |
| `admetlab_logd` | 一般 −2 ～ 6 | **LogD7.4**，血液 pH 下的真实"油性"。比 LogP 靠谱，因为它把带电形式也算进去了。RDKit 算不出来，只能靠这个工具。进脑药物一般 1–3 |
| `admetlab_pka_basic` | 一般 0 ～ 12 | 最碱性 pKa。**越高越容易在血里带正电**，带正电就穿不了膜。> 10 在 CNS MPO 里直接扣满分 |

### CNS MPO（4 列）

辉瑞的六项打分（0–6），拐点取自原文 PDF，实现见 `../Step3_04_Result_Integration/Step3_04_CNS_MPO.py`。

| 列 | 范围 | 怎么读 |
|---|---|---|
| `cnsmpo_score` | 0–6 | 六项各打 0–1 分再相加。参照：本项目入脑对照中位 4.7–4.8，GKA 候选 3.78 |
| `cnsmpo_score_variant_spread` | ≥ 0 | **换个计算口径时分数会晃多少**。因为原文用的 BioByte ClogP / ACD pKa 本项目没有，只能用替代来源；这一列 = 四个口径版本里的最大值 − 最小值。⚠ **越大越不能当真**——GKA 候选中位 0.49，对照只有 0.16。表里 `GKA_0260`（1.22）和 `GKA_0251`（1.00）晃得最厉害 |
| `cnsmpo_t0_mw` | 0–1 | 六项里**分子量**那一项的得分。MW ≤ 360 得 1.0，> 500 得 0.0，中间线性 |
| `cnsmpo_t0_tpsa` | 0–1 | 六项里**极性**那一项。40 < TPSA ≤ 90 得 1.0；≤ 20 或 > 120 得 0.0。**唯一的"驼峰"函数**——太极性不行，太不极性也不行 |

只留这两项 T0，是因为**整个 GKA 候选集的差距就集中在这两项上**
（其余四项与对照几乎持平，见 `Step3_05_Fig4_CNS_MPO_Breakdown.png`）。

⚠⚠ **CNS MPO 分高不等于能进脑。** 原文自己写着
"not intended to be used purely as a predictor of CNS penetration"，
它衡量的是"性质像不像一个 CNS 药"。
实测它在本项目对照上分辨力有限（B3DB 阳性 4.78 / 阴性 4.48，几乎重叠）。

### RDKit 本地算的结构性质（4 列）

这四列**不是预测，是从结构式数出来的**，同一个分子永远同一个答案。

| 列 | 单位 | 怎么读 |
|---|---|---|
| `mw` | Da | 分子量，**平均分子量**口径。⚠ 别和 ADMETlab 那个 `MW` 混——那个是单同位素质量，含 Cl/Br 的分子能差 3 Da |
| `tpsa` | Å² | 拓扑极性表面积，**N/O 口径**（不计 S、P）。越大越亲水越难穿膜。⚠ 项目里还有一个含 S/P 的 `tpsa_sandp`，两者在含磺酰胺的分子上能差 20 Å² 以上，**BOILED-Egg 用含 S/P 的，CNS MPO 用这个** |
| `clogp` | — | RDKit 的 Crippen LogP（片段加和法）。表里 CNS MPO 实际用的是 `admetlab_logp`，这列留作对照 |
| `hbd` | 个 | 氢键给体数（–OH、–NH 的个数）。每多一个都要多花能量脱水才能进膜 |

### GKA 这一侧：效力与骨架（5 列）

**入脑之外的另外两个维度。** 一个进得去脑但没活性的分子没有意义。

| 列 | 怎么读 |
|---|---|
| `gka_priority` | Step1_05 给的优先级 **P1 > P2 > P3 > P4**，只按效力单轴分档 |
| `gka_potency_band` | 效力档位的可读版本，如 `6.5–7.0（0.1–0.32 µM）` |
| `gka_pactivity_median` | pActivity 中位数（= −log₁₀(EC50/M)）。**越大越强**：7.0 = 100 nM，6.0 = 1 µM |
| `scaffold_cluster_size` | 这个分子所属 **Murcko 骨架**簇里有几个分子。⚠ **= 1 表示"独苗"**，是独立的化学起点；数字大表示它属于一串同系物，取 top-N 时容易一次拿一堆近亲 |
| `murcko_scaffold` | 骨架的 SMILES。⚠ 骨架把**所有环**都算进去，所以侧链上多一个环就算不同骨架——`GKA_0492` 与 `GKA_0061` 是同一化学系列（只差异丁基 vs 环己基甲基），Murcko 骨架却不同 |

⚠ 效力列在 C 组（GKA 身份对照）里有 **5 个空值**（`GKA_0783` MK-0941 药物条目、
`GKA_0784` LY-2608204、`GKA_0785` 多格列艾汀、`GKA_0786` Globalagliatin 盐酸盐、
`GKA_0787` Cadisegliatin）：它们是**零活性或活性不在 GCK 上的临床药**，
从 `drug_mechanism` / 药名词干补回来的，本来就没有 GCK 活性数据——**空值是事实，不是缺漏**。

### 结构（2 列）

| 列 | 是什么 |
|---|---|
| `std_smiles` | **标准化后**的 SMILES（已去盐、已中性化），送两个工具的就是这一串 |
| `inchikey` | 由结构算出的 27 位指纹。跨库比对、核对"是不是同一个分子"用它 |

## 几个可以直接读出来的观察（**不是结论**）

1. **两条证据线在同一个化学系列上交汇**：`GKA_0492`（两个工具都判 Yes、非 P-gp 底物）
   与 `GKA_0061`（ADMETlab 0.96、**P2 效力档**、非 P-gp 底物）
   是同一系列——同样的甲基脲 + 双吡啶醚母核，**只差一个脂溶性侧链**
   （异丁基 vs 环己基甲基），TPSA 都是 76.14。
   ⚠ 但它们的 `murcko_scaffold` **不相同**，因为环己基那个环被算进骨架里了——
   **骨架列适合找"同系物串"，不适合当"是不是同一化学起点"的唯一判据。**
2. **A 组里另外两个是同一骨架的近亲**（`GKA_0718` / `GKA_0639`，只差一个取代基），
   且**都被判为 P-gp 底物**——按"BBB+ 且非 P-gp"的口径它们会掉出去。
3. **11 个 A/B 分子只有 10 个骨架，效力集中在低档**（P2 一个、P3 三个、P4 七个）。
4. **12 个 GKA 身份对照全部被 SwissADME 判为 BBB−**，ADMETlab 也只有
   Globalagliatin（`LY-2608204`，0.90）一个例外——但它的 CNS MPO 只有 2.83、
   MW 560、口径波动 1.00，是表里最不稳的一个。
5. C 组里 CNS MPO 最高的是 `Ro-281675`（4.94）和 `PF-04991532`（4.92），
   但两者的 ADMETlab 入脑概率分别只有 0.08 和 0.00——
   **这正是"CNS MPO 分高 ≠ 能进脑"的现成例子。**
