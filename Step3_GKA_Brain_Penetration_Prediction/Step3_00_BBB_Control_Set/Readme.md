# Step3_00：构建入脑（BBB）对照集

> 本文件目前**只写目的**。做法、参数、产物、结论等做完之后再补。

## 目的

为 Step3 的入脑预测流程建一套**独立的对照集**，用来回答一个问题：

> **这条预测流程分得开「能入脑」和「不能入脑」吗？**

Step3 后续要用 SwissADME、ADMETlab 这类工具去预测 GKA 候选分子的入脑能力。
但这些工具给出的数字本身无从判断可信与否——
**必须先拿一批已知答案的分子喂进去，看它答不答得对。**
对照集就是这批已知答案的分子。

## 什么算对照

* **阳性对照** = 明确知道**能**入脑的小分子
* **阴性对照** = 明确知道**不能**入脑的小分子

「明确知道」的依据必须是**实测的脑暴露数据**，且能追溯到出处。
不接受凭印象、凭经验、凭直觉的判断。

## ⚠ 对照与 GKA 无关，也不需要有关

对照分子**不必是 GKA，不必与葡萄糖激酶有任何关系**。
它们唯一的资格是**脑暴露这件事本身已被实测确证**。

不要从 GKA 候选里挑对照，也不要因为某个对照「和本项目靶点无关」就把它换掉——
**正是因为无关，它才能独立地检验这条流程。**

## ⚠ 与「GKA 身份对照」是两套东西

项目里已有一套对照（CLAUDE.md 里那 12 个已知 GKA），
和本步要建的这套**标定的是完全不同的轴**：

| | GKA 身份对照 | 入脑对照（本步） |
|---|---|---|
| 回答的问题 | 这个分子**是不是 GKA** | 这个分子**能不能进脑** |
| 用途 | 校验 Step1 检索有没有漏掉已知的药 | 校验 Step3 预测流程有没有分辨力 |

那 12 个 GKA 对照**不参与本步**——本项目没有它们任何一个的实测脑暴露数据，
**既不能当入脑阳性对照，也不能当入脑阴性对照**。
「它们是外周药所以应该不入脑」是未经验证的推断，不是事实。

## 本步不做的事

* **不评价任何 GKA 候选分子**——本步只处理对照分子。
* **不定预测流程的合格标准**——那是 Step3_05 的事，需专门讨论。
* **不对外部数据源作对错判定**——不同数据源可能采用不同判据或适用场景，
  差异如实记录，判断留给人。
