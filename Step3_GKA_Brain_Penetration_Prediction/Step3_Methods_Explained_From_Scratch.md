# Step3 用到的四样东西，从头讲一遍

**面向的读者：** 会高中/大一化学，没接触过药物设计和计算化学。
**目标：** 读完能说清楚 RDKit、SwissADME、ADMETlab、CNS MPO 各自在干什么、
凭什么这么干、以及它们各自靠不住的地方在哪。

全文不需要你记任何公式，但会用到本项目的真实数字。

---

## 〇、先说清楚我们要回答的问题

我们手上有 **787 个「葡萄糖激酶激活剂」（GKA）候选分子**。
葡萄糖激酶（GK）是身体里管血糖的一个酶，主要在**肝脏和胰腺**工作；
激活它可以降血糖，所以这类分子当年是冲着**糖尿病**做的。

现在的问题变了：**这些分子能不能进入大脑？**

为什么要问？因为大脑里也有葡萄糖激酶，参与中枢的血糖感知。
但这批分子当初根本没往「进脑」这个方向设计——所以这是一个**事后追问**。

要回答它，最靠谱的办法是**做实验**：给动物用药，测脑子里的药物浓度。
但 787 个分子逐个做实验，成本和时间都不现实。
所以先用**计算**筛一遍——这就是 Step3 在做的事。

⚠ 一句话摆在前面：**计算给的是「预测」，不是「事实」。**
这份文档最后会讲清楚，这些预测在什么情况下可信、什么情况下不可信。

## 一、血脑屏障：为什么「进脑」这么难

血液能到全身，但大脑被一层特殊的血管壁挡着，叫**血脑屏障**（BBB）。

普通器官的毛细血管壁像**筛子**——细胞之间有缝，分子可以从缝里钻过去。
大脑的毛细血管壁像**焊死的墙**——细胞之间被"紧密连接"封住了，没有缝。

于是分子想进脑，基本只剩一条路：**从细胞中间穿过去**，
也就是**溶进细胞膜，再从另一侧出来**。

细胞膜是什么？一层**油**（磷脂双分子层）。所以：

> **能不能进脑 ≈ 这个分子能不能溶进一层油里，再从油里出来。**

这一句话是后面所有计算的物理基础。它直接引出了两个要求，而且互相矛盾：

* 要能**溶进油**里 → 分子得有点"油性"
* 溶进去以后还得**出得来**、还得先能在血里被运输 → 又不能太油

所以最好的进脑分子是**中等油性**的。太亲水进不去，太亲油卡在膜里出不来。

还有第二道关卡：**外排泵**。
脑血管细胞上装了一种叫 **P-糖蛋白（P-gp）** 的"泵"，
它会主动把已经渗进来的外来分子**再泵回血里**。
所以有些分子物理上明明能穿膜，实际却进不去脑——**被泵出去了**。
这就是为什么后面看 BBB 预测时，一定要**同时看 P-gp**。

## 二、描述一个分子的六七个数

要用计算判断"能不能溶进油里"，得先把分子变成**数**。
下面这几个量，是全篇的词汇表。

### 1. 分子量 MW（molecular weight）

所有原子量加起来。单位道尔顿（Da）。

* 水 18，阿司匹林 180，本项目 GKA 候选**中位 463**
* 越大越难穿膜——大分子挤不进紧密排列的磷脂

⚠ 一个坑：**平均分子量 vs 单同位素质量**。
氯有 ³⁵Cl 和 ³⁷Cl 两种同位素，自然界里按比例混着。
「平均分子量」按比例加权，「单同位素质量」只算最常见的那个。
含氯、含溴的分子两者能差 1–3 Da。本项目里 **SwissADME 给的是平均、ADMETlab 给的是单同位素**，
73 个分子对不上就是这个原因，不是算错了。

### 2. LogP：油水分配系数（"油性"的标尺）

把一个分子扔进"油和水"分层的瓶子里，摇匀静置，它会按比例分配到两层。

$$P = \frac{\text{油层里的浓度}}{\text{水层里的浓度}}$$

取以 10 为底的对数就是 **LogP**。

* **LogP = 0** → 油水各一半
* **LogP = 3** → 油层里是水层的 1000 倍（挺油）
* **LogP = −2** → 水层里是油层的 100 倍（很亲水）

进脑药物通常在 **LogP 2–4** 这个区间。

### 3. LogD7.4：**真实体液条件下**的油性

LogP 有个大问题：它假设分子是**中性**的。

但很多药分子会在水里**带电**：

* 含 **–COOH（羧基）** 的会丢掉一个 H⁺，变成 **–COO⁻**（带负电）
* 含 **–NH₂（胺基）** 的会抓一个 H⁺，变成 **–NH₃⁺**（带正电）

**带电的分子几乎溶不进油**（电荷喜欢水，讨厌油）。
所以一个 LogP 看着很油的羧酸，在血液里可能全是带电形式，实际根本不进膜。

**LogD7.4** 就是修正版：在**血液的 pH = 7.4** 条件下，把带电和不带电的形式都算进去的油水分配系数。

> **判断进脑，看 LogD7.4 比看 LogP 靠谱。**

本项目的 787 个 GKA 候选里有 **95 个含羧酸**，在血里带负电——
拿 LogP 当 LogD 用会严重高估它们的穿膜能力。这是项目里明确记过的一个坑。

### 4. pKa：分子有多容易带电

pKa 是"这个基团在什么酸碱度下会掉/抓一个质子"的临界点。

* **最碱性 pKa 越高** → 在生理 pH 下**越容易带正电**
* pKa = 10 的胺，在 pH 7.4 时基本 100% 带正电
* pKa = 5 的胺，在 pH 7.4 时基本不带电

CNS MPO 特意把"最碱性 pKa"列为六项之一，原因就是：
**太碱的分子在血里永远带正电，穿不了膜，还容易被 P-gp 泵盯上。**

### 5. TPSA：拓扑极性表面积

**极性**指分子表面"喜欢水"的部分——主要是**氧原子和氮原子**（以及它们上面的氢）。

TPSA 就是把分子里所有氧、氮的表面积加起来，单位 Å²（埃平方）。
它不需要真的算三维表面，只要看分子里有哪些含 N、O 的片段，查表加起来——
所以叫"拓扑"（topological，只看连接关系不看三维形状）。

* TPSA 越大 → 表面越"亲水" → 越难溶进油 → 越难进脑
* 经验上进脑药物 **TPSA < 90**，本项目 GKA 候选**中位 105**

⚠ 又一个坑：**硫（S）和磷（P）算不算进去？**
最早的定义只算 N 和 O；后来有人把 S、P 也加进去（它们也有极性）。
两种口径都在用，**同一个分子能差 20 Å² 以上**。
本项目里 GKA 候选含 73 个磺酰胺（有 S），TPSA 中位在两种口径下是 **105 vs 122**——
「TPSA ≤ 90 的分子有几个」从 181 掉到 85。所以**用哪个口径必须说清楚**。

### 6. HBD / HBA：氢键给体 / 受体的个数

**氢键**是一种较弱的吸引力：一个连在 N 或 O 上的氢（**给体**，HBD），
会被另一个分子的 N 或 O（**受体**，HBA）吸引。水分子之间就是靠氢键连着的。

对进脑来说，**HBD 是关键**：

> 分子每多一个 –OH 或 –NH，就多一份和水的牵扯。
> 要溶进油，得先把这些氢键**扯断**——每扯断一个都要花能量。

所以进脑药物的 HBD 通常很少（0 或 1）。

### 7. 骨架（Murcko scaffold）

把分子的所有"侧链"剪掉，只留下环和连接环的部分——这就是**骨架**。

一篇 SAR 论文常常合成几十个"同一个骨架、只换侧链"的分子。
它们数起来是 50 个，**化学上其实只是 1 个起点**。
本项目 1,333 个分子只有 521 个骨架，最大的一簇有 46 个分子——
所以排序时按分子取 top-50 会拿到一堆近亲，这在项目里是明确记过的坑。

## 三、RDKit：**算**出来的（不猜，只算）

**RDKit 是一个开源化学信息学库**（Python 包），本项目用 2026.03.4 版。

它做的事很纯粹：**把分子的结构式变成数**。

### 它怎么知道一个分子长什么样？

靠 **SMILES**——一种用一行字符串写分子的记法：

| SMILES | 是什么 |
|---|---|
| `O` | 水 H₂O |
| `CCO` | 乙醇（C–C–O） |
| `c1ccccc1` | 苯环（小写字母表示芳香环） |
| `CC(=O)Oc1ccccc1C(=O)O` | 阿司匹林 |

RDKit 读进 SMILES，在内存里建一张**图**：原子是点，化学键是线。
之后所有计算都在这张图上做。

### 它算的东西是"确定的"

TPSA、MW、HBD、HBA、环数、骨架——这些**不是预测，是数出来的**。
同一个分子，同一版 RDKit，永远给同一个答案。这一点和后面两个网页工具有本质区别。

LogP 稍微特殊一点：RDKit 用的是 **Crippen 方法**——
把分子拆成一堆预定义的原子类型，每种类型有一个查表得来的贡献值，加起来就是 LogP。
这个"查表值"是当年在几千个实测 LogP 上拟合出来的，
**所以 RDKit 的 LogP 带一点经验成分**，不像 MW 那样是纯粹的算术。

### 本项目用 RDKit 做的三件事

1. **标准化结构**（Step3_01）——这是送去任何工具前的必修课：
   * **去盐**：药物常以盐的形式存在，比如"某某盐酸盐"，SMILES 里带一个 `Cl.`。
     那个氯离子不是药，要扔掉，只留**母体分子**。
   * **中性化**：把 `–COO⁻` 加回 H 变成 `–COOH`，把 `–NH₃⁺` 去掉 H 变成 `–NH₂`。
     为什么？因为 **SwissADME 的 FAQ 明写：模型基本在中性分子上训练，输入请给中性形式**。
   * 1,274 个分子里去盐 8 个、中性化 8 个；有 4 个季铵盐是**永久正电荷**，
     化学上不可能中性化（氮上四个键，没有质子可掉），已单独标出。
2. **算描述符**——MW、TPSA（两种口径都算）、LogP、HBD/HBA、环数、骨架……
3. **生成 InChIKey**——一种由结构算出来的 27 位指纹字符串，
   同一个结构永远得到同一个 key。本项目**用它来核对"送出去的分子"和"收回来的分子"是不是同一个**
   （下文会讲为什么这一步救了命）。

### RDKit 给不了什么

**它算不了任何需要"实验知识"的量**：LogD、pKa、能不能进脑、会不会被 P-gp 泵出去。
这些不是从结构图上能推出来的，得靠模型或实验——这就是后面两个工具存在的理由。

## 四、SwissADME：一条**画在图上的线**

**SwissADME**（瑞士生物信息学研究所，网页免费）。
输入一批 SMILES，返回每个分子的一堆性质和几个 Yes/No 判断。

### 它的 BBB 预测其实是**一个几何图形**

SwissADME 判断"能不能进脑"用的是叫 **BOILED-Egg**（"煮鸡蛋"）的方法，
思路简单到有点可爱：

1. 拿一批**已知能进脑**和**已知不能进脑**的分子
2. 以 **TPSA 为横轴、LogP 为纵轴**，把它们画成散点图
3. 发现能进脑的都挤在**左上角**（低极性、中等油性）的一小片区域里
4. 在那片区域外面**画一个椭圆**——这就是"蛋黄"
5. 以后来一个新分子，算出它的 (TPSA, LogP)，**落在蛋黄里就判 Yes，落在外面就判 No**

（还有一个更大的"蛋白"椭圆，判的是能不能被肠道吸收。）

所以：

> **SwissADME 的 `BBB permeant` 不是机器学习模型，是一条画死的边界线。**

本项目实测验证过这一点：141 个判 No 的分子里，**没有一个**落在 58 个判 Yes 的分子
围成的区域内部——两组完全可以用一条线分开。**这就是几何规则的指纹**。

**这意味着什么？**
它只用了两个数（TPSA 和 LogP）。任何这两个数以外的信息，它都看不见。

### 它的 P-gp 预测才是真模型

同一份结果里的 `Pgp substrate`（是不是外排泵的底物）就不一样了：
81 个判 No 的分子落在判 Yes 的分子围成的区域**内部**——
说明它不是靠 TPSA/LogP 画线画出来的，**用了别的信息**。

> ⇒ **下游不能只看 `BBB permeant`，必须配合 `Pgp substrate` 一起看**，
> 否则"能穿膜但会被泵出去"这种情况完全看不见。

### 用它时踩到的坑

* **一批最多 200 个**，且官方要求**串行**（跑完一批再跑下一批）。1,274 个分子分了 7 批。
* **`iLOGP` 和 5 个 CYP 预测整列返回 `n/d`（没算出来）**。
  是它依赖的商业组件停止对学术网站支持的后果，不是我们的输入有问题。
* **⚠⚠ 它返回过一个我们从没提交过的分子。**
  第 6 批里名叫 `B3D_0441` 的那一行，名称是对的，
  但返回的结构是**樟脑**（MW 152）——而我们提交的是三氟丙嗪（MW 352）。
  樟脑根本不在本项目的 1,274 个分子里，推测是浏览器会话残留。
  更麻烦的是，这一行的 BBB 判断从 No 翻成了 Yes。

  **只核对名称是发现不了的**。所以现在的规矩是：
  **凡是网页工具的结果，回填前必须逐行比对"提交的结构"和"返回的结构"的 InChIKey，不符的整行剔除。**
  1,391 行里就抓到这 1 行，但如果没抓到，它会悄悄污染一个阳性对照。

## 五、ADMETlab 3.0：**学**出来的（机器学习）

**ADMETlab 3.0**（中南大学，网页免费）。同样是输入 SMILES，但它返回 **123 列**。

### "机器学习模型"在这里是什么意思

拿 BBB 这一项举例，它的训练过程大致是：

1. 收集几千个**已知**能进脑/不能进脑的分子（有实验数据的）
2. 把每个分子变成一串数字（分子指纹 / 描述符）
3. 训练一个模型，让它学会"从这串数字猜出标签"
4. 训练完，给一个新分子，模型输出一个 **0 到 1 之间的概率**

所以：

> **ADMETlab 的 `BBB` 是概率（0.87 这样的小数），不是 Yes/No。**
> 它和 SwissADME 的二分类**不能直接对齐**。

模型见过的分子越多、越接近你要预测的分子，结果越可信。
反过来——**如果你的分子和训练集里的分子长得很不一样，模型的输出就是外推，不可信**。
这一点在本项目里非常要紧，第七节会展开。

### 它给了两个别处拿不到的关键值

| 列 | 是什么 | 为什么重要 |
|---|---|---|
| **`logD`** | LogD7.4 | RDKit 算不了，CNS MPO 的第 3 项非它不可 |
| **`pka_basic`** | 最碱性 pKa | RDKit 算不了，CNS MPO 的第 6 项非它不可 |
| `pgp_sub` / `BCRP` / `MRP1` / `BSEP` … | 七种转运体 | 比 SwissADME 只有一个 P-gp 丰富得多 |

拿到这两列，CNS MPO 的六项输入才凑齐——这是本项目非要用它的直接原因。

### 用它时踩到的坑

* **它不接受分子名称**，输入只能是一列光秃秃的 SMILES。
  ⇒ **回填只能靠行序**。行序一旦错位，后面全错，而且**不会报错**。
* 好在它把输入**原样放在 `raw_smiles` 列返回**，所以除了行序还能按结构独立校验。
  实测 16 批 1,571 行**逐字一致**，一行没错位。
* 页面写"最多 1000 个"，但实测 646 个/批会超时；本项目用 **98 个/批**，跑了 16 批。
* 它的 API 是坏的（主计算端点必然 500），只能走网页上传。

### 两个工具在 P-gp 上给出几乎相反的图景

| | SwissADME | ADMETlab |
|---|---|---|
| GKA 候选判为 P-gp 底物 | **51.8%** | 概率中位 **0.001**（几乎全说不是） |

不同模型、不同训练集、不同输出形式，**分歧本身不算错误**。
但这说明一件事：**多个工具一致时可以更有底气，不一致时不能简单投票**。
BBB 这一项两个工具高度一致，P-gp 这一项则近乎相反。

## 六、CNS MPO：一把**打分尺**（不是预测器）

**CNS MPO** = Central Nervous System Multiparameter Optimization，
辉瑞公司 2010 年提出的评分方法。

原文（本仓库里有 PDF）：
Wager TT, Hou X, Verhoest PR, Villalobos A.
*"Moving beyond Rules: The Development of a Central Nervous System Multiparameter
Optimization (CNS MPO) Approach To Enable Alignment of Druglike Properties."*
**ACS Chem Neurosci 2010;1(6):435–449**，doi:10.1021/cn100008c

### 它要解决的问题：**硬门槛太粗暴**

传统做法是设一堆硬线："MW 必须 ≤ 500"、"TPSA 必须 ≤ 90"。
问题是 MW = 501 的分子并不比 499 的差多少，但硬线会**直接砍掉它**。

CNS MPO 的做法是把每条硬线换成一条**斜坡**：

```
理想 1.0 ├────────────●
         │             ╲
         │              ╲          ← 中间是线性过渡，不是断崖
         │               ╲
最差 0.0 │                ●────────
         └────────────────────────
                 MW 360      500
```

* MW ≤ 360 → 这一项得 **1.0 分**（最理想）
* MW > 500 → 这一项得 **0.0 分**
* 中间**线性过渡**：MW = 430 → 得 0.5 分

六项各自这么打一次分，**加起来就是总分，范围 0–6**。

### 六项分别是什么，拐点在哪

（下表逐字取自原文 Table 1 与 Figure 4，不是凭印象写的）

| 项 | 形状 | 得 1.0 分 | 得 0.0 分 | 为什么是这一项 |
|---|---|---|---|---|
| **cLogP** | 单调下降 | ≤ 3 | > 5 | 太油会有安全性和代谢问题 |
| **cLogD7.4** | 单调下降 | ≤ 2 | > 4 | 体液条件下的真实油性 |
| **MW** | 单调下降 | ≤ 360 | > 500 | 太大穿不过膜 |
| **TPSA** | **驼峰** | 40 < TPSA ≤ 90 | ≤ 20 或 > 120 | 太极性穿不过，**太不极性也不行** |
| **HBD** | 单调下降 | ≤ 0.5 | > 3.5 | 氢键越多越难脱水进膜 |
| **最碱性 pKa** | 单调下降 | ≤ 8 | > 10 | 太碱在血里永远带正电 |

**TPSA 是唯一的"驼峰"**——两头都不好，中间才好。
其余五项都是"越小越好"。

### 怎么验证我们实现对了

原文 Table 4 给了一个完整算例：
输入 ClogP 3.1 / ClogD 1.7 / TPSA 21.0 / MW 392.5 / HBD 1.0 / pKa 9.2，
六项得分应为 0.95 / 1.00 / 0.05 / 0.77 / 0.83 / 0.40，**总分 4.0**。

本项目的实现**把这个算例（以及原文 Table 3 的三个候选药）写死在脚本的自检里**，
六项和总分全部复现才允许出分，对不上直接退出。
这样"拐点抄错一个数"这种错误不可能溜过去。

### ⚠ 最容易被误用的一点

原文自己写了一句（第 446 页）：

> *"the algorithm is **not intended to be used purely as a predictor of CNS penetration**"*
> （这个算法**不是**用来单独预测入脑的）

CNS MPO 是**设计工具**：它衡量的是"这个分子的性质是否落在 CNS 药物常见的区间里"，
是一种**成药性对齐**，不是"能不能进脑"的物理预测。

一个分子 CNS MPO 得 5 分，只说明"它的性质像一个 CNS 药"，
不代表它真的进得去脑（还有 P-gp、转运体、代谢等一堆因素）。
反过来也一样。

所以本项目里 CNS MPO 是**三个视角之一**，不是裁判。

## 七、三个工具的关系，和它们共同的天花板

### 一句话对比

| | 它在做什么 | 结果是否唯一确定 | 靠什么 |
|---|---|---|---|
| **RDKit** | **算** 结构本身的量 | ✅ 同样输入永远同样输出 | 分子图上的算术 + 查表 |
| **SwissADME** | **查** 一条画好的边界线 | ✅ 规则确定（但网页会改版） | 两个数（TPSA、LogP）画的椭圆 |
| **ADMETlab** | **猜**（用学过的数据） | ⚠ 概率值，模型会静默更新 | 几千个已知分子训练的模型 |
| **CNS MPO** | **打分**（性质像不像 CNS 药） | ✅ 公式确定 | 六条人为定的斜坡 |

它们不是互相替代，而是**三个不同的视角**：
结构本身（RDKit）→ 经验规则（SwissADME、CNS MPO）→ 数据模型（ADMETlab）。

一致时更有底气，不一致时**要如实报告分歧**，而不是取平均糊过去。

### 本项目为工具的不稳定专门做的两件事

1. **每一批都混进同一组 20 个"锚点"分子**（重复提交）。
   网页模型会悄悄更新，7 批/16 批不是同时跑的。
   同一个锚点在不同批给出不同结果，就是漂移的**直接证据**。
   实测：SwissADME 20 个锚点 × 7 次 × 48 列，**分歧 0**；
   ADMETlab × 16 次 × 122 列，最大差 **6×10⁻⁸**（浮点噪声）。所以这一轮没有漂移。
2. **逐行核对提交与返回的结构**（上文那条樟脑）。

### ⚠⚠ 最大的那个天花板：**外推**

所有这些模型/规则，都是从**已知的分子**上总结出来的。
如果要预测的分子和当初那批分子长得很不一样，**总结出来的规律未必还成立**。

本项目正好撞上这件事：

| | 分子量中位 | TPSA 中位 |
|---|---:|---:|
| 能进脑的对照 | 319 | 44 |
| **不能进脑的对照** | **366** | **89** |
| **GKA 候选** | **463** | **105** |

**GKA 候选的两个数都超过了"不能进脑"那组**——
它不是落在两类对照**之间**，而是整体**越过**了两者。

这意味着：**工具在对照集上分得开，不代表在 GKA 候选上同样可靠。**
对照集再怎么挑也够不到 GKA 所在的那片区域（这已经从两个方向验证过了）。

所以本轮的产物只是**数据**：
"哪些分子在哪个工具下得了什么值"。
**"这个流程算不算合格"、"哪些 GKA 值得往下推"，是下一步（Step3_05）要专门讨论的事**，
而且讨论的第一个议题就是这个外推问题。

## 八、名词速查

| 词 | 一句话 |
|---|---|
| **BBB** | 血脑屏障，大脑血管上那道"焊死的墙" |
| **P-gp** | 一种外排泵，把渗进来的分子再泵回血里 |
| **MW** | 分子量 |
| **LogP** | 油水分配系数的对数，"油性"标尺（假设分子中性） |
| **LogD7.4** | 血液 pH 下的真实油性，**带电形式也算进去** |
| **pKa** | 分子掉/抓质子的临界酸碱度；最碱性 pKa 越高越容易带正电 |
| **TPSA** | 拓扑极性表面积，分子表面"亲水"部分的大小 |
| **HBD / HBA** | 氢键给体 / 受体的个数 |
| **SMILES** | 用一行字符串表示分子结构的写法 |
| **InChIKey** | 由结构算出的 27 位指纹，用来核对"是不是同一个分子" |
| **Murcko 骨架** | 把侧链剪光后剩下的环系，用来判断"是不是同一类分子" |
| **描述符** | 从结构算出来的任何一个数（MW、TPSA…统称） |
| **Kp,uu** | 脑内**游离**药物浓度 / 血浆**游离**药物浓度，进脑能力的金标准之一 |
| **logBB** | 脑内**总**浓度 / 血浆**总**浓度，另一种口径（含组织结合，与 Kp,uu 不是同一个量） |
| **CNS MPO** | 辉瑞的六项打分（0–6），衡量"性质像不像 CNS 药" |
| **锚点分子** | 每批都重复提交的同一组分子，用来发现工具漂移 |
